Open it in

Private windows are off for Cascade. Chrome lets an extension open them only after you turn on Allow in Incognito for it.

Chrome restarts Cascade when you change that setting, so this request ends: start the run again once it's on.

What happens if you allow it
  • The run gets a new window, not any tab you have open. It closes when the run ends.
  • In a normal window, that's your own Chrome, so sites you're signed in to see you signed in. A private window starts signed out of everything.
  • Sent to your Cascade server while it runs: the addresses of pages in that window, their text and structure, and what the run types into them. No screenshots, unless you tick the box for them: then still pictures of the run's window, with password, card and one-time-code fields and other sites' frames blurred.
  • A page in the run can save a file to your Downloads. Cascade stops the run when that happens but doesn't delete the file.
  • Sites on your private network (localhost, your router, office addresses) can't be allowed here. Use the Cascade CLI or desktop app for those.
  • While the run is open, WebRTC in all your tabs goes without UDP, so a video call elsewhere may get worse until it ends. Until Chrome restarts, background workers of the sites you allow can't reach your private network, even in your own tabs.
  • You can stop it any time: close the window, or press Stop in the Cascade button in the toolbar.
