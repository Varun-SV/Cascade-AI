What happens if you allow it
  • The run gets a new window, not any tab you have open. It closes when the run ends.
  • That window is your own Chrome, so sites you're signed in to see you signed in.
  • Sent to your Cascade server while it runs: the addresses of pages in that window, their text and structure, and what the run types into them. No screenshots.
  • A page in the run can save a file to your Downloads. Cascade stops the run when that happens but doesn't delete the file.
  • Sites on your private network (localhost, your router, office addresses) can't be allowed here. Use the Cascade CLI or desktop app for those.
  • You can stop it any time: close the window, or press Stop in the Cascade button in the toolbar.
